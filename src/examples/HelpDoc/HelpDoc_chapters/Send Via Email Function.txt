[>c] # Send Via Email

# Why
WareWoolf has a built-in function for emailing drafts to yourself as an easy means of backup and file transfer. This is because it is designed for ease of use in a standalone writerDeck in which the user may not have access to any other software.

# How
WareWoolf currently only supports sending emails through Gmail. To do this, you have to create an App Password for your gmail account (on the Gmail website: https://support.google.com/accounts/answer/185833?hl=en) and then use that password when you send emails through WareWoolf.

WareWoolf does not save your password as plaintext. By default, it hands your password to your operating system's own secure keystore to encrypt (the same mechanism your browser or OS password manager relies on), tied to your login on this machine. If you'd like another layer on top of that, check "Protect With Passphrase?" when saving the password, and WareWoolf will encrypt it with a passphrase of your choosing instead--it will ask you for this once per session, and cannot recover it for you if you forget it. (On a machine with no system keystore available at all, WareWoolf falls back to a key file in its own settings folder. That still keeps a copied settings file or backup useless to someone else, but it won't stop someone who can already read your files on this computer--that's exactly what the passphrase option is for.) All that said, no security is perfect, so just in case, I still recommend you create a free gmail account specifically to use for sending drafts to yourself. Then you put that into WareWoolf as the sender adress, and for the recepient address you can put your primary email. Then if an evil hacker in a hoodie hacks into your computer and gets past all that, all they have is an account with a bunch of "sent" emails containing your poorly written smut. (And you can even set up gmail to automatically delete these so they won't even get that.)

This works perfectly for me. At the end of each day's writing session, I hit "Send via Email" and rest easy knowing it is now backed up in my email. But I make no promises about anything, as I am just a fool in Indiana and know nothing, so use at your own risk, etc. etc.

# File Formats
You can choose to email the current chapter or the entire project compiled in the format you wish. It defaults to whatever settings you last used in the "Compile" tool. If you select to email the Project File, this works differently--it creates a compressed .zip file of your .woolf project file and .txt chapter files all together so you can easily back up everything with your notes, etc., intact.

All of the above also applies to the "Send Error Log Via Email" function.
