[>c] # Wi-Fi Transfer

This tool is only available in Linux, in the File menu under Send via Email. It moves files between the writerDeck and a phone or laptop on the same Wi-Fi network, both ways, without an email password: the book or a backup goes to the other device, and chapters or notes you wrote there come back to the deck.
	**Connecting.** Open File > Wi-Fi Transfer and tick “Switch On”. The dialog shows an address, like http://192.168.1.20:8080, and a six-digit code. Type the address into the browser on your phone or laptop, then type the code. The code works once, for one device; **New Code** makes another and disconnects whatever was using the old one.
	**Sending to the other device.** Choose Chapter, Compiled or Project and a file type, the same choices as Send via Email, and press **Add to Page**. The file appears on the page with a Download button. Project sends a backup .zip of the whole project.
	**Sending to the deck.** On the page, choose files and press Send. They go into the deck’s inbox (the “WareWoolf Inbox” folder in your Documents) and wait there; nothing is imported until you say so. In the dialog, choose a file in the Inbox list and press **Import** (or Enter): the Import dialog opens on that file, with the file types that can read it. A .zip backup opens as a restored copy, the way File > Restore Backup does. **Discard** (or Delete) removes a file from the inbox. You can work through the inbox later with Wi-Fi Transfer switched off.
	The deck takes only the kinds of file Import can read (.docx, .txt, .md, .mdfc, .html, .epub, .fountain, .fdx, .fadein) and .zip backups, up to 50 MB each, and never replaces a file already in the inbox: a second “Chapter 9.docx” arrives as “Chapter 9 (2).docx”.
	**When it switches off.** Wi-Fi Transfer is off whenever the dialog opens, and switches off when the dialog closes, after ten minutes with nothing sent, or after five wrong codes. Whatever was offered on the page is taken down; the inbox stays.
	**Keep in mind.** Only devices on the deck’s own network can reach the page. It is plain HTTP, though, so on a shared network (a café, a library) others on that network could see what is sent. At home that is not a concern; elsewhere, send only what you would not mind being seen, or use Send via Email.
	If the dialog says the deck is not on a local network, join one in the Wi-Fi Manager first.
