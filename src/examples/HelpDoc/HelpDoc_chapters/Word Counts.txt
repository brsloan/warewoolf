[>c] # Word Count

WareWoolf allows you to view several word counts:
* Entire project word count
* Chapter word count
* Session word count

It also allows you to enter a word count goal, and it will then show you a progress bar which turns from red to green as you approach your goal.

Each of these counts is followed by an estimate of how many pages it comes to, like "1000 wds / ~4 pgs". A page that is only partly filled still counts as a page, so the estimate always rounds up.

The Words Per Page field is what that estimate divides by. It starts at 300, the traditional double-spaced manuscript page, but if you count pages some other way you can set your own--and whatever you set is remembered the next time you open WareWoolf, for every project. Clearing the field simply hides the estimates and leaves the word counts on their own.
